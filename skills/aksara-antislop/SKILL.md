# Aksara Anti-Slop Core Skill

When building or reviewing interfaces:
1. Every technique must serve a functional purpose.
2. Dose caps: limit glow and glassmorphism to max 1-2 focal elements.
3. Apply Liveliness Dials (ENERGY, RHYTHM, MOTION) from 1 (Calm) to 3 (Bold).
4. Run internal Delivery Gate self-audit before shipping.
