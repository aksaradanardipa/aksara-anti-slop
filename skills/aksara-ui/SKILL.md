# Aksara UI Skill

- Light Mode Priority for enterprise, public service, financial, and industrial domains.
- Maximum 2-3 core brand colors + 1 deliberate accent color.
- Consistent 8-point / 4-point spacing grid.
- No bento-grid or circular 3-step templates unless required by actual content.
