# Aksara Code Craftsmanship Skill

- ZERO CODE COMMENTS: Do not write // or /* */ comments in code files.
- Anti-monolith: Limit component files to 150-200 lines max.
- Strict data contracts: TypeScript interfaces for all data models.
- Action Locking: Instant button disabling on submission to prevent duplicate processing.
- Non-sequential Public IDs: Token-based identifiers to prevent enumeration attacks.
