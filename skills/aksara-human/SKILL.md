# Aksara Human & Accessibility Skill

- WCAG AA text contrast: minimum 4.5:1 for normal text, 3:1 for large text.
- Keyboard navigable: Tab, Shift+Tab, Enter, Space, and Escape for modals.
- Mandatory 5 UI States: Ideal, Loading skeleton, Empty, Error with retry, Edge/Max.
- Senior-friendly UX: Centered floating modals with explicit "✕ Close (Esc)" buttons.
