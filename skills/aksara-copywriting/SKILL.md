# Aksara Copywriting Skill

- STRICT BAN: Em dash (`—`) character is completely forbidden in agent copy. Use comma, period, colon, or parentheses.
- BANNED BUZZWORDS: Seamless, Revolutionary, Next Generation, AI-Powered, Cutting Edge.
- SPECIFIC CTAs: Use contextual calls-to-action like "Create Work Order" or "Start Free Trial" instead of "Get Started".
- Real evidence over fabricated statistics.
