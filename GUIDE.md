# Installation & User Guide

This guide walks you through installing, using, and updating **Aksara Anti-Slop Agent**.

## Installation Methods

### Method 1: Global Plugin (Antigravity)
Clone or install directly into your Antigravity plugins directory:
```bash
git clone https://github.com/aksaradanardipa/aksara-anti-slop.git ~/.gemini/config/plugins/aksara-anti-slop
```

### Method 2: Project Rule (AGENTS.md)
Add the pointer block to your project's `AGENTS.md`:
```markdown
# Aksara Anti-Slop
For UI, copywriting, and code standards, refer to:
https://github.com/aksaradanardipa/aksara-anti-slop
```

## How Delivery Gate Works
Before any code or UI deliverable is handed over, the agent runs a mandatory 4-block self-audit:
1. **Hard Gate:** Verify no em dashes, no fake stats, no dead links, and full keyboard accessibility.
2. **Purpose-Gate:** Ensure any gradient, shadow, or visual treatment has an articulable 1-line reason.
3. **Liveliness:** Verify ENERGY, RHYTHM, and MOTION dials are set and respected.
4. **Craftsmanship:** Verify 5 UI states, zero code comments, and action locking.
